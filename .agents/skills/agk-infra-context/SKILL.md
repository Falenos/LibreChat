# AGK Infra Context

This skill is the operational map for Agentic Karl infrastructure. Use it before changing deployment workflows, Azure resources, Key Vault secrets, ArgoCD apps, Helm values, or environment config.

Last verified: 2026-06-02.

## Rules

- Prefer GitOps repo changes over live mutations. Live Azure/Kubernetes/Argo changes are for validation, emergency repair, or secret rotation.
- Do not print or store secret values. It is fine to inspect secret metadata, IDs, update timestamps, and enabled status.
- Before mutating ArgoCD or Kubernetes, run read-only checks and/or dry-runs first.
- Use `argocd ... --grpc-web` for `argocd.agk.nonprod.knauf.digital`.
- For Key Vault rotations consumed as env vars, refresh ExternalSecret first, then restart the Deployment so pods reload env.

## New AGK ArgoCD Wiring

The new dev Argo app is generated by an ApplicationSet in:

- `agk-deployment-configs/infra/nonprod/argocd/projects/services.yaml`

For the main app it uses multi-source Helm values:

1. `agk-deployment-configs/agentic-karl/dev/services/agentic-karl/values.yaml`
2. `$serviceValues/infrastructure/dev/values.yaml` from `Knauf-Group/agentic-karl`

The second value file is applied later and can override the first. When updating the AGK dev image tag, update both:

- `agk-deployment-configs/agentic-karl/dev/services/agentic-karl/values.yaml`
- `agentic-karl/infrastructure/dev/values.yaml`

Also keep `SERVICE_VERSION` in `agentic-karl/infrastructure/dev/values.yaml` aligned with the image tag.

## Release Workflow

Current intended flow for merged app PRs:

1. Existing CT release job builds and publishes the image to `acrctshared001`.
2. AGK deploy job imports the same image tag into `acragkhubnonprod001`.
3. Workflow commits the new tag to both AGK value locations.
4. New AGK ArgoCD auto-syncs; workflow can refresh/poll `agentic-karl-dev-agentic-karl`.

The reusable CT workflow does not expose `new-version` as a `workflow_call` output. If needed, recompute the released version after the CT release job succeeds by checking out `main` and reading `package.json`:

```bash
VERSION="v$(npm pkg get version | tr -d '"')"
```

## Approved Live Operations After Confirmation

Force ExternalSecret refresh:

```bash
ts=$(date -u +%Y-%m-%dT%H:%M:%SZ)
argocd app patch-resource agentic-karl-dev-agentic-karl \
  --kind ExternalSecret \
  --group external-secrets.io \
  --namespace agentic-karl-dev \
  --resource-name agentic-karl-secrets \
  --patch "{\"metadata\":{\"annotations\":{\"force-sync\":\"$ts\"}}}" \
  --patch-type application/merge-patch+json \
  --grpc-web
```

Restart app Deployment:

```bash
argocd app actions run agentic-karl-dev-agentic-karl restart \
  --kind Deployment \
  --resource-name agentic-karl \
  --grpc-web
```
