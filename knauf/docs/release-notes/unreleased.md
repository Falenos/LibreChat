# Unreleased KARL user changes

Append one user-visible change per row. Weekly publishing removes only shipped rows.

| Date       | Ticket   | English                                                                                                              | German                                                                                                                                                |
| ---------- | -------- | -------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-09-24 | KK20-385 | Recent conversations now appear reliably in the history, month groups are ordered newest-first, and browsing across history pages no longer skips conversations with identical timestamps. | Aktuelle Unterhaltungen erscheinen jetzt zuverlässig im Verlauf, Monatsgruppen werden mit dem neuesten Monat zuerst sortiert, und beim Blättern durch den Verlauf werden Unterhaltungen mit identischen Zeitstempeln nicht mehr übersprungen. |
| 2026-09-22 | KK20-368 | File translation can now detect the source language for machine-readable PDF, DOCX, XLSX, TXT, and CSV files before applying approved terminology; KARL asks for the language for scanned documents, presentations, images, or unreliable detection. | Die Dateiübersetzung kann die Ausgangssprache für maschinenlesbare PDF-, DOCX-, XLSX-, TXT- und CSV-Dateien jetzt vor der Anwendung freigegebener Terminologie erkennen; bei gescannten Dokumenten, Präsentationen, Bildern oder unsicherer Erkennung fragt KARL nach der Sprache. |
| 2026-09-21 | KK20-367 | File translation now defaults to one file attached to the current message; KARL asks users to choose when several current files could apply and uses historical files only when they are explicitly named or all files are requested. | Die Dateiübersetzung verwendet jetzt standardmäßig eine an die aktuelle Nachricht angehängte Datei; wenn mehrere aktuelle Dateien infrage kommen, bittet KARL Nutzende um die Auswahl und verwendet frühere Dateien nur, wenn sie ausdrücklich benannt werden oder alle Dateien angefordert sind. |
| 2026-09-21 | KK20-366 | Newly translated files now retry one brief storage-read miss automatically, so the first download click succeeds without needing a second click. | Neu übersetzte Dateien wiederholen jetzt einen kurzen Speicherlesefehler automatisch, sodass der erste Download-Klick ohne einen zweiten Klick erfolgreich ist. |
| 2026-09-21 | KK20-366 | Generated-file downloads remain unavailable until KARL has finished the response, preventing downloads before the file is ready. | Downloads erzeugter Dateien bleiben deaktiviert, bis KARL die Antwort abgeschlossen hat, und verhindern so Downloads, bevor die Datei bereit ist. |
| 2026-09-21 | KK20-339 | Conversations can recover automatically from up to two transient Model Router interruptions before any answer or tool action starts, without replaying work after output is visible or the provider has completed the response. | Unterhaltungen können sich automatisch von bis zu zwei vorübergehenden Unterbrechungen des Model Routers erholen, bevor eine Antwort oder Tool-Aktion beginnt, ohne Arbeit nach sichtbarer Ausgabe oder nach Abschluss der Antwort durch den Anbieter erneut auszuführen. |
| 2026-09-17 | KK20-353 | If the current streamed answer stops after answer text is visible, KARL keeps that text and marks it as potentially incomplete; tool-only and earlier-phase activity retain the normal error treatment. | Wenn die aktuelle gestreamte Antwort nach sichtbarem Antworttext abbricht, behält KARL den Text bei und kennzeichnet ihn als möglicherweise unvollständig; reine Tool-Aktivität und frühere Phasen behalten die normale Fehlerbehandlung. |
| 2026-09-16 | KK20-348 | IDML translations now verify that source font and style references are preserved and fail explicitly if they change; plain-text and data formats no longer request irrelevant font review. | IDML-Übersetzungen prüfen jetzt, dass die ursprünglichen Schrift- und Stilreferenzen erhalten bleiben, und schlagen bei Änderungen ausdrücklich fehl; bei reinen Text- und Datenformaten wird keine irrelevante Schriftprüfung mehr verlangt. |
