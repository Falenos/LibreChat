# Decision paper reference

Adapt this structure to the decision. Keep the ask and recommendation visible without forcing the reader through the full document.

```markdown
# <Specific title naming the decision>

**Prepared by:** <name or TBD> | **Date:** <date> | **Decision needed by:** <date or TBD>
**Decision requested from:** <person, role, or body>

## The ask

<What should be approved, funded, rejected, or chosen, including evidenced cost.>

## Recommendation

<Recommended option and the strongest reason.>

## The problem and baseline

<Current situation, affected people, and measured or explicitly estimated baseline. No solution advocacy.>

## Options considered

| Option        | What it involves | Full cost | Value | Reason to choose or reject |
| ------------- | ---------------- | --------- | ----- | -------------------------- |
| Do nothing    |                  |           |       |                            |
| <Alternative> |                  |           |       |                            |
| <Recommended> |                  |           |       |                            |

## Value and proof

<What improves, for whom, the primary measure, measurement owner, and review date.>

## Full cost

<Purchase or licence, implementation, integration, internal effort, training, ongoing operation, renewal, exit, and stopping. Mark quoted versus estimated.>

## Risks

| Risk | Impact | Likelihood | Mitigation | Owner |
| ---- | ------ | ---------- | ---------- | ----- |

## Assumptions

| Assumption | Evidence status | Consequence if false | Confirmation owner |
| ---------- | --------------- | -------------------- | ------------------ |

## Stakeholders and approvals

| Person or body | Decide, approve, consult, or inform | Lead time | Owner |
| -------------- | ----------------------------------- | --------- | ----- |

## Plan

<Decision-level milestones, dates or TBD, and owners.>

## Kill criteria

<The result that would stop the work, when it is reviewed, and who decides.>

## Open questions

| Question | Who can answer | What it blocks |
| -------- | -------------- | -------------- |

## Decision requested

<One sentence the decision maker can approve or reject.>
```
