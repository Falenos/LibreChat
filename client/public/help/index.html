Prompts, chat prompts, and agent instructions

Type What it is When to use it
Prompt A reusable request saved in the Prompt library. You can insert it into a chat and edit it before sending. Use it when you or your team repeat the same starting request, format, or checklist.
Chat prompt The message you send in the current conversation, including its goal, context, files, and desired output. Use it for the task in front of you. It guides this conversation; it does not permanently change an agent.
Agent instructions Persistent guidance configured by an Agent Builder: role, boundaries, workflow, tone, and output rules. Use it when the same behavior should apply every time that agent is used. Keep task-specific details in the chat prompt.

Rule of thumb: repeatable request → Prompt library; current task → chat prompt; repeatable agent behavior → agent instructions.

Write a useful chat prompt

  1. State the outcome you need.
  2. Add the relevant context or files.
  3. Name constraints such as audience, language, length, or deadline.
  4. Describe the desired output format.

Never place passwords, API keys, or other secrets in prompts, chats, files, or agent instructions.

Prompts und Anweisungen Neuigkeiten

Prompts, Chat-Prompts und Agentenanweisungen

Typ Was ist das? Wann wird es verwendet?
Prompt Eine wiederverwendbare Anfrage aus der Prompt-Bibliothek. Sie kann in einen Chat eingefügt und vor dem Senden bearbeitet werden. Verwenden Sie sie, wenn Sie oder Ihr Team dieselbe Anfrage, dasselbe Format oder dieselbe Checkliste wiederholen.
Chat-Prompt Die Nachricht im aktuellen Gespräch mit Ziel, Kontext, Dateien und gewünschtem Ergebnis. Verwenden Sie ihn für die aktuelle Aufgabe. Er steuert dieses Gespräch, ändert einen Agenten aber nicht dauerhaft.
Agentenanweisungen Dauerhafte Vorgaben eines Agent Builders zu Rolle, Grenzen, Ablauf, Ton und Ausgabe. Verwenden Sie sie, wenn dasselbe Verhalten bei jeder Nutzung des Agenten gelten soll. Aufgabenspezifische Details gehören in den Chat-Prompt.

Faustregel: wiederholbare Anfrage → Prompt-Bibliothek; aktuelle Aufgabe → Chat-Prompt; wiederholbares Agentenverhalten → Agentenanweisungen.

Einen hilfreichen Chat-Prompt schreiben

  1. Nennen Sie das gewünschte Ergebnis.
  2. Fügen Sie den relevanten Kontext oder Dateien hinzu.
  3. Nennen Sie Vorgaben wie Zielgruppe, Sprache, Länge oder Termin.
  4. Beschreiben Sie das gewünschte Ausgabeformat.

Geben Sie niemals Passwörter, API-Schlüssel oder andere Geheimnisse in Prompts, Chats, Dateien oder Agentenanweisungen ein.

Neuigkeiten in KARL

Verfügbare nutzerbezogene Versionshinweise stehen hier, neueste zuerst.

4.–14. August 2026

  • Geplante Agenten: wiederkehrende Projektaufgaben erstellen, sofort ausführen und Zeitpläne zentral verwalten.
  • Bessere Artefakte: SVG-Grafiken bearbeiten, frühere Versionen wiederherstellen und geteilte Artefakte zuverlässiger exportieren oder fortsetzen.
  • Projektwissen: Upload- und Verarbeitungsstatus sehen, Fehler erneut versuchen und Projektdateien synchron halten.
  • Prompts teilen: Prompts über die vorhandenen Zugriffsrechte mit berechtigten Kolleginnen und Kollegen teilen.
  • Klarere Antworten: kürzere direkte Antworten auf einfache Fragen und sicherere Wiederholungen bei unterbrochenen Modellausgaben.
  • Zuverlässigere Chats und Dateien: weniger doppelte Antworten, automatische Wiederherstellung von Bildlinks und klarere Upload-Fehler.
